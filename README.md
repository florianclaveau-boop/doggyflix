# Doggyflix

Lecteur de chaînes TV gratuites, de streamers Twitch, de films du domaine public et de vidéos YouTube, pilotable à la télécommande.

- Chaînes : liste publique [iptv-org](https://github.com/iptv-org/iptv)
- Films : classiques muets du domaine public hébergés par [Internet Archive](https://archive.org)
- Twitch et YouTube : lecteurs officiels intégrés

Le site tient en un seul fichier : `index.html`.
